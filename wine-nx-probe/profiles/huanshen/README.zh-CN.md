# 寰神结适配包

目标为已核对的 `Nascence/Exe/RPG.exe`（692224 字节），不是同名的《幽城幻剑录》程序。封面来自本轮原盒照片，经 imagegen 提取、校正透视并移除售价及右下蓝色方形标签，输出600×900 PNG。本包不包含完整游戏 EXE、游戏资源或存档。

## 配置与兼容文件

- 单游戏设置为 `title=寰神结`、`d3d=dxvk`、`locale=zh_CN.UTF-8`、`address-space=32-bit`。打包时去除设备诊断配置中的 `profile=1` 和 `verbose=0`，不主动开启性能采样或详细日志。
- EXE 定时器补丁将 pending 标记移到 `PostMessageA(WM_TIMER)` 之前，避免消息被提前消费后遗留 pending 状态。补丁只调整文件偏移 `31480`（`0x7af8`）起的 13 字节；原 SHA-256 为 `12e51a6ef11daa926acffa19ae251190618456fe0680900ef02f0e9b7e0b4ab6`，结果为 `47806963b38b35d624db5285e04196ede34bcd0948f041e060b00f3086bafbf0`。原字节为 `ff15c0314900c605845a4a0001`，新字节为 `c605845a4a0001ff15c0314900`。不匹配的 EXE 应由现有适配框架在文件安装前拒绝。
- `Bass.dll` 取本次寰神结真机回读的完整离线展开版，245248 字节，SHA-256 `108b09f0c105268eda9072148eb66beba24e3903472bd337b0cae62edcaa9611`，配套 `BOX64_DYNAREC_SELFMOD=0`。寰神结原库与幽城原库逐字节相同：88412 字节，SHA-256 `a696c391432ceb19b3f491cc63f01df1c918c87569186cf340f2f6c6b82da514`；展开版亦与幽城包一致，保留原导出及音频实现，避免运行时 Petite 自修改解包。
- cnc-ddraw 使用仓库 `swordman/ddraw.dll` 和对应 MIT 许可；其 SHA-256 `85e0f7d530dfda134793a57cb3e76b0287dcc96892ee57162dd68f47283b03a9` 与寰神结设备原库一致。`ddraw.ini` 使用本次寰神结部署后回读版本：`[RPG] hook=1`、1280×720 无边框窗口、零原点、`maintas=true`；保留 `adjmouse=true` 和 `fixchilds=2`，不叠加 Autorun 的 aspect-fit/window-fit。
- B 映射鼠标右键，用于需要右键的菜单操作；＋映射 Esc，用于跳片头。其余按键保留主程序默认映射。上述操作在寰神结中的最终效果仍待真机确认。

适配包使用现有文件替换与 EXE 补丁机制，无需新增主程序功能。兼容文件源自 `diagnostics/huanshen-start-20261003-231925/readback/`；语言配置依据 `diagnostics/huanshen-popup-20261003-233143/readback/RPG.wine-nx.txt`。没有使用幽城的 EXE 补丁。

## 验证与恢复边界

本轮手工部署后，BASS 已通过原先失败的加载阶段，随后游戏显示“只支持简体中文系统”弹窗并主动退出，未再次出现此前的 BASS 解壳访问异常。原程序调用 `GetSystemDefaultLangID` 后要求 `0x0804`，当时实际返回 `0x0409`；弹窗原因已经定位。单游戏 `locale=zh_CN.UTF-8` 已通过现有功能上传并读回核对，没有修改或跳过游戏的语言检查。

**增加 locale 后尚未获得启动或玩法验收，不能宣称修复完成。** 后续仍需验证语言弹窗是否消失、能否进入游戏，以及视频、音乐音效、画面比例、输入触屏、存读档、退出重启和持续运行。本地已核对精确补丁可重现设备 EXE 完整哈希，以及配置与 DLL 和对应回读逐字节一致；这些检查不能代替真机验证。本次加入标题、明确 32 位地址空间且不主动启用诊断采样，完整适配包安装流程也需另行验证。

现有适配框架会备份安装前的文件和设置；恢复时还原实际安装前内容。若游戏已手工打过补丁或更换过 DLL，适配包不会补造原版备份，应保留此前的 MTP 回退备份。完整 EXE、原照片、生成提示词、设备日志和主机验证工具均不进入运行包。
