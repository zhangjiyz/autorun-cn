# 幽城幻剑录适配包

目标为已核对的 `Castle/exe/RPG.exe`（471040 字节），不是同名的《寰神结》程序。封面采用用户确认的无价格版，PNG 尺寸为 600×900；包内不含完整游戏 EXE、游戏资源或存档。

## 配置与兼容文件

- `locale=zh_CN.UTF-8`、DXVK、32 位地址空间；不在包中开启调试日志或性能采样。
- EXE 定时器补丁将 pending 标记移到 PostMessage 之前，修复消息被提前消费时的等待竞态。只修改文件偏移 `0x4d05` 起的18字节；原 SHA-256 为 `0d91a37be26273ec2ebec4515badf9e17778b06397101892f27438c070acea5f`，结果为 `764bb64b4b9cc99c2040b3c3e2715b5552bda3f3ee6e4bd32cf960263a1c31cd`。不匹配的 EXE 会在文件安装前拒绝。
- `Bass.dll` 为本次用户游戏原库的完整离线展开版，保留其导出与音频实现；避免运行时 Petite 自修改代码。原库88412字节，SHA-256 `a696c391432ceb19b3f491cc63f01df1c918c87569186cf340f2f6c6b82da514`；展开版245248字节，SHA-256 `108b09f0c105268eda9072148eb66beba24e3903472bd337b0cae62edcaa9611`。配套 `BOX64_DYNAREC_SELFMOD=0`。
- 使用已核对的 cnc-ddraw（SHA-256 `85e0f7d530dfda134793a57cb3e76b0287dcc96892ee57162dd68f47283b03a9`）与 MIT 许可，复用仓库 `swordman` 中完全相同的文件。游戏专用 `ddraw.ini` 取最后设备读回版本：`hook=1`、1280×720 无边框窗口、原点为零、`maintas=true` 保持4:3居中。沿用 cnc-ddraw 的触屏/鼠标逆缩放，不叠加 Autorun 的 aspect-fit 或 window-fit。
- B 为鼠标右键，用于菜单返回；＋为 Esc，用于跳片头。其余按键保留主程序默认映射。

适配包使用现有 v5 文件替换与 EXE 补丁机制，无需新增主程序功能。五项替换文件及安装前配置由现有事务机制备份。文件替换校验包内新文件哈希，不要求旧 Bass.dll 的哈希匹配；本包针对上述已核对游戏版本。

## 验证与恢复边界

此前手工部署已确认能进入游戏、视频和音效恢复，并修正画面位置。最后一次4:3配置、触屏边缘、B退出读档、＋跳片头，以及完整存读档和持续运行仍待真机验收。本次整理加入默认简体语言、标题和明确32位地址空间，独立适配包安装流程需另行真机验证。

从原版安装时，EXE补丁先保存原文件；文件和配置恢复到安装前实际内容。若游戏已手工打过补丁或更换过 DLL，包不会补造原版备份，须保留此前的 MTP 回退备份。完整EXE、原照片、生成提示词、诊断日志和主机验证工具均不进入运行包。
