# 《三国赵云传2·纵横天下》适配包 v1

目标是当前提供的 `zhaoyun2/Game.exe`，原始 SHA-256 为
`9fc36a955a6addaa8727bd9fd972dbe226c4094b19455b469094b3063c8214ce`。
本包沿用一代的显示、触屏和手柄映射，并使用同一代码位置的绝对鼠标模式补丁。
补丁仍由启动器按完整 SHA-256 校验、备份和恢复；其他版本不会被修改。
真机启动失败的根因是游戏目录自带的 dgVoodoo `DDraw.dll` 初始化失败。
API 11 起，安装时会校验这份 DLL 的 SHA-256
`0279b2a2a8d8f208bb0d40131d6ae42cbee9c271f234cb4a25dac9914d0d27b4`，
将其停用并保留为 `DDraw.dll.autorun-disabled`；“恢复上次配置”会还原它。
其他版本的同名 DLL 不会被停用。适配包不包含游戏文件、DLL 或存档。

选择游戏目录根部的 `Game.exe`，然后在“游戏配置 → 常规 → 适配包更新”中
选择“三国赵云传2·纵横天下”。游戏目录已有 `DDraw.dll`、`D3D8.dll`、
`D3D9.dll` 和 `D3DImm.dll`（dgVoodoo）。本包只停用上述精确版本的
`DDraw.dll`，保留其余文件。旧版主程序无法应用此包，需先更新到 API 11。

真机已确认停用本地 `DDraw.dll` 后能够启动；新包内的自动停用流程仍需重新上机验证。
Switch 上仍需逐项验证
画面、触屏和摇杆移动、按键、MP3 音乐、Indeo AVI 视频、音效、存档、
读档、退出和重启。按键映射目前与一代相同，二代的实际操作尚待确认。
