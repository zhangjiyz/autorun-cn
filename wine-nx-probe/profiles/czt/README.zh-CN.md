# 苍之涛字体测试适配包

用于游戏根目录 `SWDMD_GB.EXE`，不是 `czt.exe`（该文件是 RAR 自解压程序），也不是另一份 `SWDMD.EXE`。保留用户提供的 `d3d=dxvk`、`aspect-fit=800x600` 和按键；添加游戏库标题。四个空键值 PLUS/MINUS/STICKL/STICKR 规范为等效的 0。

左摇杆及十字键发送方向键；右摇杆移动鼠标，触屏操作鼠标；A/Y 空格确认，B Esc 取消，X Enter 菜单，L M 地图，R R 走跑，ZL/ZR Q/E 旋转。保留的 RLEFT/RRIGHT 在 RSTICK=mouse 下不会发送 Q/E。

本包使用简体环境 locale=zh_CN.UTF-8，并附精确哈希字体补丁。只改目标 SWDMD_GB.EXE 文件偏移 0xc7dc 起的 31 字节：字体构造函数固定传入原程序已有的 GBK“宋体”常量 0x4e3210，同时将 lfQuality 改为 NONANTIALIASED_QUALITY=3，保留原字号、字距、字重、字符集、文字表面及缓存。补丁绑定原 SHA-256，修改前由现有框架保存 EXE，恢复适配可还原原程序；无需新增主程序功能。包中不包含完整 EXE、字体、DLL、游戏数据、User.cfg 或存档。

2026-10-03 只读诊断：真机 `SWDMD_GB.EXE` 与本地文件相同，983040 字节，SHA-256 `5906d20c1a56a65b6d9fcd08db1fd1a72063c357eb5f1409a941f21c2de031a8`。本轮读取日志时的真机配置只有 d3d=dxvk，日志 LCID=0x0409；debug.txt 记录 GDI 及游戏初始化完成。该日志未记录实际选中的字体，也没有确认字体异常画面的本轮复现。

EXE 的字体构造函数 0x40c78f 使用 CreateFontIndirectA，字号上限 64、负高度、宽度 0、字重 400、GB2312_CHARSET=134、默认绘字质量 0。初次构造在 0x40c492 传入 0x4e3210 的 GBK“宋体”；后续 0x472623、0x474b91、0x4981cf 等位置传入 0x4e7634 的 b2 d3 a9 fa c5 e9，即 Big5“細明體”。简体版中存在字体名编码混用，实际 ANSI 环境及字体替代结果需要进一步验证；不能把日志 LCID 直接当成实际字体选取证据。

GDI 文字写入 64×64 的临时表面，先用两个空格清理，再 TextOutA 绘字。0x40daf0 将白色文字复制为一位字形；0x40db54 对每个 16 位像素只判断是否非零，0x40db6c 将其置为实心。灰色抗锯齿边缘因此也会成为完整笔画。这与《轩辕剑肆》已修复路径存在相同缺陷，但尚未以苍之涛的实际字体选择或对比画面确定两项各自影响。
