# 仙剑奇侠传三配置

目标是游戏根目录的 32 位 `PAL3.exe`。适配包包含启动器设置、控件，以及已核对的三份 PAL3patch 5.1 文件；不包含游戏本体。游戏使用 Direct3D 9、Bink 和 Miles Sound System；目前使用 WineD3D，32 位 DXVK 在该游戏初始化时失败。

本地原游戏随附 PAL3patch 2.1（2020-06-01）；真机使用 PAL3patch 5.1（2025-06-01）。`PAL3patch.conf`、`PAL3patch.dll`、`PAL3.dll` 从本轮真机测试的文件逐字节核对后加入适配包。最初偶发的启动崩溃尚未定位到单独原因，不能把后续成功启动当作已修复。

安装时直接覆盖同目录的三份补丁文件，并纳入配置包事务备份、失败回滚和“恢复配置”。这三份文件不参与设置合并；`PAL3.wine-nx.txt`、按键、作弊和封面仍按原流程处理。补丁文件要求运行时 API 7；模拟触摸时长的固定位置点击要求 API 10。游戏自己的 `config.ini` 不带入配置包：真机的 `motionblur` 改回 1 后，已与本机文件逐字节一致。`PAL3patch.conf` 中的 `nolockablebackbuffer=0` 是真机已验证的视频流畅设置。

## 已保留的修复

| 问题 | 当前处理 | 作用范围 |
|---|---|---|
| 睡觉场景被黑色覆盖层遮住 | 跳过已确认的 1280×720 黑色绘制 | `pal3-black-overlay-skip=1` 且进程为 `PAL3.exe` |
| 游戏帧间隔为 0，剧情不推进 | 修正 Box64 ARM64 dynarec 的 FNSAVE/FRSTOR 80 位浮点转换方向 | x87 指令语义修复，对使用这些指令的游戏均生效 |
| 流畅视频显示在角落 | 将视频源区域 `(0,75)–(800,525)` 呈现在窗口中央 | `pal3-movie-center=1` 且进程为 `PAL3.exe` |
| 地震视频后剧情停住、声音循环噪音 | 保留用户确认正常时的配置组合，其中 `profile=1` 仍开启 | PAL3 配置；原因尚未通过单变量测试确定 |

两个 PAL3 专用开关相互独立，值为 `0` 或删掉该行即关闭对应修复。`wined3d-explicit-buffer-flush=0` 也只在 PAL3 配置生效。`profile=1` 会产生线程采样日志；它出现在唯一确认片尾剧情与声音正常的真机组合中，因此暂时保留。要清除这项日志，需要单独关闭后在真机复测片尾。视频缩放保持用户接受的居中效果，不再调整为铺满屏幕。

当前源码已定向编译，NRO、D3D9 和 WineD3D DLL 已上传真机并读回核对。用户重新测试后确认仙剑三目前运行无问题；配置包内三份 PAL3patch 5.1 文件的安装与恢复流程通过主机测试，尚未在真机上从配置包完整安装和恢复。

## 控件

| Switch 控件 | 游戏输入 |
|---|---|
| 左摇杆 | 方向键；首次推动自动短按、松开、再持续按住，触发游戏的双击奔跑 |
| 十字键 | 方向键移动，保持原有按键行为 |
| 右摇杆左右 | A / D 转动镜头 |
| A | 空格，互动 |
| B | Esc，取消或返回 |
| X | 点击屏幕右下角 `(1100,700)` |
| + | 在屏幕右上角坐标 `(1240,40)` 点击一次，模拟触摸菜单按钮 |
| Y | Enter，确认 |
| R | Tab，迷宫切换角色或主界面切换分页 |
| 右摇杆按下 | 未映射 |
| L | Q；官方说明书未列出对应功能 |
| - | M；此版本中作用待实机确认 |
| 左摇杆按下 | Shift；此版本中作用待实机确认 |
| 触屏 | 鼠标移动和左键点击 |
| ZR / ZL | 鼠标左键 / 右键 |
