# 仙剑奇侠传三外传·问情篇首版适配包

目标是游戏根目录的 32 位 `PAL3A.exe`。首版包包含启动器设置、按键、空金手指列表和封面，不包含游戏本体、存档或补丁 DLL。封面根据用户提供的实体盒封照片整理成 600×900 图片，保留“外传”红印，去除了拍摄背景、零售贴纸及底部促销小字，并非原盒封的逐像素扫描。游戏目录中已有的 `PAL3Apatch.conf`、`PAL3Apatch.dll` 和 `PAL3A.dll` 原样保留；不要安装仙剑三的 `PAL3patch` 文件。

本地样本的 `PAL3A.exe` 为 1392128 字节，SHA-256 为 `e49b35bb0add6b2872cc362ce72ddecd737b0c38d0a4bebaec19c462c204a304`。游戏说明文件要求 DirectX 9，目录中带有 Bink 和 Miles 音频 DLL。`config.ini` 与本地仙剑三相同，均为 800×600、32 位色、全屏。现有 `PAL3Apatch` 插件日志标记为 1.9 版，配置中的 `nolockablebackbuffer=1` 保持原值。包里使用 WineD3D 和键盘映射作为首轮测试起点；未移植仙剑三只针对 `PAL3.exe` 的黑色覆盖层与电影居中修正，也未沿用仙剑三专属的固定坐标点击。

## 首轮按键

| Switch 控件 | 发送给游戏的输入 |
| --- | --- |
| 左摇杆、十字键 | 方向键；左摇杆带双击奔跑序列 |
| 右摇杆左右 | A / D，预计用于转动镜头 |
| A / B / Y | 空格 / Esc / Enter |
| X / - | M |
| L / R | Q / Tab |
| + | Esc |
| ZR / ZL | 鼠标左键 / 右键 |
| 触屏 | 鼠标移动与左键点击 |
| 左摇杆按下 | Shift |

这些按键沿用仙剑三的基本操作思路，外传尚未在 Switch 上验收；若菜单位置或操作不同，应依据实机画面和本轮日志单独调整。

## 首轮实机验收

1. 选择游戏根目录的 `PAL3A.exe`，安装 `pal3a` 适配包并启动。
2. 分别检查启动、片头视频、主菜单、场景、战斗和剧情画面，记录黑屏或定位异常。
3. 检查音乐、音效、摇杆与触屏；确认 A、B、Y、+ 等键在菜单和游戏内的实际作用。
4. 新建存档、完全退出后重新进入并读档，再检查退出与持续运行。
5. 遇到失败，保留本次启动的游戏日志与画面，先确认其版本和时间，再做单项调整。
